# 鸿学伴 App 学习闭环总规划

> 状态：2026-07-01 Codex 主线约束。竞赛交付重心是 HarmonyOS App；Vercel 仅为无状态真实 Agent 网关。

## 一、产品主线

鸿学伴不是课程列表加聊天框，而是一个可验证的自学循环：

`设定目标 -> 学习课程内容 -> 主动练习 -> 即时反馈 -> 错题复盘 -> 间隔复习 -> 掌握度提升 -> 获得真实成就`

参考成熟产品的可复用原则：

- Khan Academy：按知识点掌握度推进，允许学生持续练习到真正掌握，而不是只计算浏览次数。
- Quizlet Learn：由目标、熟悉程度和多种题型组成个性化学习路径，错题需要再次作答。
- Anki：主动回忆与间隔重复，答错内容更早进入下一次复习。
- Duolingo：连续学习只用于建立习惯，里程碑反馈来自真实完成行为，不替代学习质量。
- 国内题库与 MOOC：课程、练习、测验、错题、收藏、笔记、学习报告组成闭环；进度必须对应具体任务完成状态。

## 二、信息架构

顶层保持四个入口，避免重复导航：

1. **今日**：唯一下一步、真实今日任务、待复习项、快速问学伴。
2. **课程**：课程 -> 章节 -> 知识点 -> 课程内容/精选练习/扩展资源。
3. **学伴**：真实 AI 对话，带课程上下文、引用、服务状态和重试。
4. **我的**：画像、学习记录、错题本、收藏、成就、通知设置。

独立详情流程：

- `CourseDetail -> Lesson -> Practice -> QuizResult -> Review`
- `Knowledge -> ResourceDetail -> 外部可信资源`
- `My -> ActivityRecords / MistakeBook / Achievements`

## 三、真实状态模型

ArkData 下一版本使用以下领域状态，UI 不直接维护展示百分比：

- `LessonProgress`：课程、章节、知识点、开始/完成时间、有效学习状态。
- `QuizAttempt`：题目来源（curated/ai）、作答、正确性、用时、解析查看、重做次数。
- `TopicMastery`：累计题数、正确率、最近学习、下次复习、掌握级别。
- `StudyEvent`：lesson_started、lesson_completed、quiz_submitted、mistake_reviewed、task_completed。
- `ReviewItem`：错题/薄弱知识点、到期时间、复习间隔、状态。
- `Achievement`：规则 ID、解锁条件、解锁时间；只从 StudyEvent 推导。

课程进度由已完成必修单元占比计算；掌握度由练习正确率、重复作答和复习结果计算。当前首页写死的 65%/42%/30% 只作为迁移前种子，完成领域迁移后必须删除。

## 四、内容与 AI 边界

- **课程内容**：打包在 HAP 或只读 API，包含目标、前置知识、正文、例子、来源、复核状态。
- **精选题库**：离线可做，答案和解析来自已审计题库；提交前不展示答案。
- **AI 出题**：联网调用豆包，失败时明确不可用，不回退成精选题库并冒充 AI。
- **学伴讲解**：携带课程 ID、知识切片引用、画像和最近 12 条历史；引用可打开对应课程内容。
- **外部资源**：显示来源、类型、适用知识点和离开 App 提示；只收录已审计 URL。
- **教程质量**：每个知识点必须有学习目标、先修项、事实来源、示例、练习映射和最近复核日期；未经复核的模型文本不得写回课程正文。

## 五、迭代顺序

### P0 可学习闭环

1. 建立领域模型与 ArkData schema v2 迁移。
2. 将 147 条知识切片、60 道选择题及外部资源打包为端侧只读资产。
3. 完成课程详情、章节内容、精选练习、结果与错题重做。
4. 首页进度和任务全部改为事件推导。

### P1 复习与激励

1. 错题本、收藏、学习记录。
2. 间隔复习队列与今日到期任务。
3. 成就页、连续学习、里程碑动画；只使用真实事件。
4. 服务卡片展示下一项本地任务，通知直达对应任务。

### P2 Agent 深度融合

1. 错题一键请求学伴讲解并携带题目/知识点上下文。
2. 学伴回答引用课程切片，可跳回知识点。
3. AI 计划生成后转换为本地任务，完成情况反哺画像。
4. AI 出题与精选题库使用统一答题器，但来源标签、失败策略和数据记录严格分离。

## 六、验收门槛

- 任一进度数字可追溯到 ArkData 事件和计算规则。
- 离线时课程、精选练习、错题、记录、成就可用；AI 明确不可用。
- 课程内至少可完整完成一次“学习 -> 5题练习 -> 结果 -> 错题重做 -> 进度变化”。
- 每个卡片只有一个明确主操作；同一功能在顶层只出现一个入口。
- 所有新增页面适配当前手机分辨率，并通过 CLI 构建、模拟器交互和大阶段视觉验收。

## 七、暂缓待办

- **先锋视觉系统与星云图高级美术**：当前浅层换色、普通发光和单点截图验收不作为最终方向。后续先做成熟学习产品与开发者学习产品拆解，明确行为路径、动机反馈、信息密度、动效节奏和可量化学习洞察，再进入实现。
- **学习反馈系统统一化**：所有长耗时 AI 动作、检索、生成、评分、同步和提交都必须有明确进度反馈、阶段文案、失败恢复与可取消策略；不能让用户面对空白区域判断是否卡死。
- **题目标签化分析**：每题必须具备知识点、能力类型或错误类型标签，记录页和画像页后续基于标签汇总薄弱项、正确率、复习节奏和学习建议。
