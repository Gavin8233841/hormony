### Topic: TCP握手与挥手

#### cs103_q04
- **题目摘要**：TCP 建立连接的三次握手中，第二次握手报文中的标志位为？
- **正确答案**：B. SYN=1, ACK=1
- **难度**：medium
- **理由**：需要理解三次握手的完整过程，回忆第二次握手是服务器同时回复 SYN 和 ACK。选项 A 是第一次握手，选项 C 是第三次握手，选项 D 是挥手标志，干扰项设计有针对性，需要 2 步推理（回忆握手过程 + 识别具体步骤的标志位）。
- **问题**：无

#### cs103_q25
- **题目摘要**：TCP 四次挥手后，主动关闭方进入 TIME_WAIT 状态并等待 2MSL 的主要原因？
- **正确答案**：B. 确保最后一个 ACK 到达对方并防止旧连接报文干扰新连接
- **难度**：medium
- **理由**：需要理解 TIME_WAIT 的设计目的而非简单记忆，涉及 2-3 步逻辑链：（1）确保最终 ACK 可重传到达，（2）使旧连接报文在网络中消亡。选项 A、C、D 都有一定迷惑性但明显不如 B 全面。
- **问题**：无

#### cs103_q31
- **题目摘要**：TCP 三次握手中，SYN 报文中序列号（seq）的作用是？
- **正确答案**：B. 初始化发送方的发送序列号
- **难度**：easy
- **理由**：直接记忆 SYN 报文中 seq 字段的作用，属于 TCP 基础概念，选项区分度高（确认数据、初始化序列号、通告窗口、请求关闭分别对应不同字段/标志位）。
- **问题**：无

#### cs103_q32
- **题目摘要**：TCP 连接建立过程中，客户端发送第一个 SYN 后进入的状态是？
- **正确答案**：B. SYN_SENT
- **难度**：easy
- **理由**：直接记忆 TCP 状态转换，客户端发送 SYN 后进入 SYN_SENT 是标准知识点，选项中 LISTEN 是服务器初始状态、SYN_RCVD 是服务器收到 SYN 后的状态、ESTABLISHED 是握手完成后的状态，区分度高。
- **问题**：无

#### cs103_q33
- **题目摘要**：TCP 四次挥手中，被动关闭方收到 FIN 后首先发送的报文标志位为？
- **正确答案**：B. ACK=1
- **难度**：medium
- **理由**：需要理解四次挥手过程，推断被动关闭方收到 FIN 后的第一步动作是回复 ACK（而非立即发送 FIN）。选项 C（FIN=1）是迷惑项，因为被动关闭方最终也会发送 FIN，但不是"首先"发送的。需要 2 步推理。
- **问题**：无

## 四、审计总结

### 总体难度分布

cs103 题库整体难度偏低，easy 占 72.7%（40/55），medium 占 27.3%（15/55），hard 占 0%（0/55）。难度分布呈现明显的"底部堆积"形态，缺少高难度题目来区分高水平学生。理想的三级难度分布建议为 easy 40-50%、medium 35-45%、hard 10-20%。

### 各 Topic 难度梯度

11 个 Topic 中，3 个 Topic（OSI与TCP/IP模型、HTTP协议、网络层与IP协议）的 5 道题全部为 easy，完全没有难度梯度。HTTPS与TLS Topic 是唯一以 medium 为主的 Topic（4 medium + 1 easy），难度相对合理。TCP握手与挥手 Topic 的梯度较好（2 easy + 3 medium）。建议在所有 Topic 中至少保持"3 easy + 1 medium + 1 hard"或"2 easy + 2 medium + 1 hard"的梯度结构。

### 答案正确性

全部 55 道题的答案经逐题核验，均与计算机网络技术事实一致，未发现答案错误。解析内容准确、充分，能够有效帮助学生理解知识点。特别是 q27（非对称加密在 HTTPS 中的用途）和 q45（前向保密）的解析涉及现代 TLS 的精确描述（RSA 用于签名、ECDHE 用于密钥交换），技术细节准确。

### 发现的主要问题

1. 缺少 hard 难度题目（0 道），无法有效区分高水平学生
2. 3 个 Topic 全部为 easy，缺乏难度梯度
3. 计算类题目严重不足（仅 1 道），子网划分等核心计算能力未被考查
4. q53 选项 C 干扰性不明确，不对应常见计算错误
5. q15 题目表述与选项范围略有不匹配
6. 多个重要知识点未被覆盖（CSMA/CA、交换机原理、HTTP/2、VPN 等）
7. q16 和 q26 考查维度重复

### 改进建议

1. **增加 hard 题目**：补充 5-8 道需要综合分析、多步计算或边界条件判断的高难度题目，重点覆盖 TCP 拥塞控制数值推演、子网划分计算、TLS 握手流程分析等
2. **均衡 Topic 难度**：在 OSI、HTTP、网络层三个全 easy Topic 中各替换或增加 1-2 道 medium/hard 题目
3. **增加计算题**：补充子网划分、IP 分片偏移量、香农定理、TCP 拥塞窗口等计算题
4. **扩大知识点覆盖**：补充 CSMA/CA、交换机原理、HTTP/2、VPN、DHCP 等重要知识点
5. **优化选项设计**：修正 q53 选项 C，使其对应明确的计算错误模式
6. **修正题目表述**：调整 q15 题干以匹配选项范围
7. **减少重复考查**：将 q16 或 q26 之一升级为 DNS 综合分析题
