## 1. 冻结叙事与可用证据

作品定位：面向大学计算机课程的鸿蒙原生学习伴侣。学生在课程中先学、先答；错题带着题目与实际作答进入“小鸿”，获得针对性解释和一个可执行的学习动作；计划和 AI 测验把后续学习安排与结果留在本机。现有课程为数据结构、操作系统、计算机网络。财务会计、英语和外部题库是后续试点方向，**不写成已交付功能**。

本轮可录主路径（Pura X View 模拟器，1320×2232）：

1. 今日或课程进入“数据结构 → 数组与线性表”，阅读内容并完成五题固定练习；故意把删除顺序表元素的移动次数选成 `n-i+1`，本轮显示 `4/5`、正确答案 `n-i`、解析和“已保存”。
2. 点击“问学伴”。会话顶部显示“已提交作答 · 数组与线性表”，预填“这道题我做错了，帮我讲清楚怎么判断。”；真实云端回答指出多算了一个元素，用 `n=5、i=2` 举例，再给一题自查，并附“去练习”行动和三条可展开资料。
3. 今日进入“学习计划”，以“一周掌握 TCP 基础／7 天”生成，页面显示“计划已保存”、当天“学习 OSI 与 TCP/IP 模型”，点击“学习”到对应原生课节。此步独立展示计划能力，不把计划任务冒称由上一步错题自动生成。
4. 我的学习进入“操作系统 → 进程与线程”AI 测验，选择“速练／进阶”，云端生成五题；提交后显示 `4/5`、一题错因、标签表现，累计答题由 35 变为 40、错题由 12 变为 13。该测验与前述数据结构错题属于**不同主题的能力展示**，视频中不要剪成一次自动闭环。

## 2. 可直接改写的提交文稿

**一句话创意（100 字内）**：鸿学伴把课程、练习和 AI 学伴连成一条学习路径，让大学生从一道错题出发，得到具体讲解、后续练习与可回看的进度。

**作品介绍初稿（控制在 800 字内）**：

> 鸿学伴是一款面向大学计算机课程的 HarmonyOS 原生学习应用。学生可在数据结构、操作系统和计算机网络课程中按主题学习，通过分步示例和精选练习先形成自己的判断。答错后，学伴接收题目、实际作答和提交状态，指出具体误区，并给出课程内容、练习或复习等可点击的下一步。学伴回答可查看资料引用；未提交的练习先给提示，不提前透露答案。
>
> 应用还可按学习目标生成计划，并围绕课程主题生成不同难度的 AI 测验。作答结果、错题、课程进度与学习记录保存在本机，回到首页和“我的学习”即可继续。云端服务承担模型调用与学习建议，本机负责学习状态和动作执行；模型不可直接改写学习记录，也不能打开任意目标。
>
> 复赛版本聚焦一条可操作的学习过程：课程学习、真实作答、错因讲解、后续练习和结果回看。演示使用 Pura X View 模拟器及线上模型服务。当前不包含账号同步、教师后台、语音输入或外部题库导入；生成内容仍需学生结合课程资料判断。

**技术方案句式**：ArkUI/ArkTS 构建 HarmonyOS 原生页面；ArkData 保存学习状态；Next.js API 在 Vercel 提供无状态 Agent 编排，火山方舟模型负责辅导、计划和出题；检索从已整理的课程资料与外链索引中选取引用，Safety 检查输入和输出，受控动作只路由到已有课程主题。此为实现说明，不能写成自主多 Agent、自动事实核验或跨设备同步。

**创新与价值写法**：

- 把已提交的题目和实际答案带进辅导，而不是只把课程名塞进通用对话；本轮 `n-i+1` 错因可在原生回答中核对。
- 学伴给出的下一步是有课程与主题边界的页面动作，学生点击后才执行；计划和测验结果由原生应用保存，云端模型不直接改写本机记录。
- 用分步课节、固定练习和按主题生成的测验组成连续学习入口；课程资源标明来源，站外资料只打开链接，不把外部内容复制进题库。

**AI 使用说明初稿**：产品运行时通过火山方舟调用 `doubao-seed-2-1-pro-260628`，用于错因解释、学习计划与按主题出题；开发及材料制作使用的其他 AI 工具、具体采用内容和人工复核人，待团队填入最终 NOTICE。模型输出可能出错，引用和结果只为学习参考；固定题与生成题的答案质量需要人工抽查。不得把这段初稿冒充已经由团队签署的正式声明。
