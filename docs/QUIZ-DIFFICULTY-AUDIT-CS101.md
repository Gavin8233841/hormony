### Topic: 数组与线性表

#### cs101_q01
- **题目摘要**：在一个长度为 n 的顺序表中删除第 i 个元素，需要移动多少个元素？
- **难度**：easy
- **理由**：直接记忆性题目，只需知道删除操作需要将第 i+1 到第 n 个元素前移，共 n-i 个。属于单步判断。
- **问题**：无

#### cs101_q02
- **题目摘要**：动态数组倍增扩容策略，每次插入操作的均摊时间复杂度为？
- **难度**：medium
- **理由**：需要理解均摊分析的概念，不是简单的复杂度记忆。需知道倍增扩容总代价为 O(n)，均摊到每次插入为 O(1)，涉及 2-3 步逻辑链。
- **问题**：无

#### cs101_q03
- **题目摘要**：关于顺序表和链表的比较，下列说法正确的是？
- **难度**：medium
- **理由**：需要综合理解顺序表（缓存友好、随机访问 O(1)）和链表（已知位置插删 O(1)）的特性，逐一排除错误选项，涉及多个知识点的比较。
- **问题**：无

#### cs101_q28
- **题目摘要**：在顺序表（数组）中，访问第 i 个元素的时间复杂度为？
- **难度**：easy
- **理由**：直接记忆性题目，顺序表支持随机访问 O(1)，是顺序表最基本性质。
- **问题**：无

#### cs101_q29
- **题目摘要**：关于线性表的说法，错误的是？
- **难度**：easy
- **理由**：概念辨析题，需知道线性表可采用顺序存储或链式存储两种方式。"只能采用顺序存储结构"明显错误，单步判断即可。
- **问题**：无

### Topic: 链表

#### cs101_q04
- **题目摘要**：在双链表中，在节点 p 之后插入新节点 s，正确的指针赋值顺序是？
- **难度**：hard
- **理由**：需要逐一分析四个选项中多步指针赋值顺序的正确性，判断哪种顺序不会导致链表断裂。每个选项涉及 4 步指针操作，需仔细推演赋值顺序对节点引用的影响，选项干扰性强，容易因一步顺序错误而选错。
- **问题**：无

#### cs101_q06
- **题目摘要**：在单链表中查找第 i 个节点的时间复杂度为？
- **难度**：easy
- **理由**：直接记忆性题目，单链表不支持随机访问，需从头遍历，复杂度为 O(n)。
- **问题**：无

#### cs101_q30
- **题目摘要**：逆置一个单链表的时间复杂度为？
- **难度**：easy
- **理由**：需知道逆置操作需遍历所有节点并逐一修改指针，每个节点 O(1)，共 n 个节点，总计 O(n)。属于单步推理。
- **问题**：无

#### cs101_q31
- **题目摘要**：带头节点的单链表 L 为空的判断条件是？
- **难度**：easy
- **理由**：需知道带头节点链表的结构特点，头节点始终存在，空表条件为 L->next == NULL。属于概念记忆。
- **问题**：无

#### cs101_q32
- **题目摘要**：在已知节点位置的条件下，单链表插入和删除操作的时间复杂度为？
- **难度**：easy
- **理由**：直接记忆性题目，已知位置时只需修改指针 O(1)。需注意"已知位置"这一前提条件，但整体仍为单步判断。

### Topic: 二叉树与BST

#### cs101_q10
- **题目摘要**：在任意二叉树中，若叶子节点数为 n0，度为 2 的节点数为 n2，则下列关系成立的是？
- **难度**：medium
- **理由**：需要通过边数关系进行推导：总边数 = n0+n1+n2-1 = n1+2*n2，化简得 n0=n2+1。涉及 2-3 步逻辑链，需理解树的边数与节点度的关系。
- **问题**：无

#### cs101_q11
- **题目摘要**：在二叉搜索树（BST）中删除一个有两个子节点的节点，通常采用的方法是？
- **难度**：medium
- **理由**：需要理解 BST 删除操作的策略，知道用中序后继（或前驱）替换被删节点。需理解原理后判断，涉及对 BST 性质的理解。
- **问题**：无

#### cs101_q36
- **题目摘要**：具有 n 个节点的完全二叉树的深度为？
- **难度**：medium
- **理由**：需要理解完全二叉树的性质并进行推导：深度为 k 的完全二叉树节点数范围为 2^(k-1) 到 2^k-1，反推深度 k = 楼log2(n)+1。涉及对数推导。
- **问题**：无

#### cs101_q37
- **题目摘要**：一棵有 n 个节点的平衡二叉搜索树（BST），查找操作的时间复杂度为？
- **难度**：easy
- **理由**：直接记忆性题目，平衡 BST 高度为 O(log n)，查找复杂度为 O(log n)。
- **问题**：无

#### cs101_q38
- **题目摘要**：对二叉树进行前序遍历的访问顺序是？
- **难度**：easy
- **理由**：直接记忆性题目，前序遍历顺序为根-左子树-右子树（NLR），是基本概念定义。
- **问题**：无

### Topic: AVL树与红黑树

#### cs101_q13
- **题目摘要**：在 AVL 树中，新节点插入到某节点的左孩子的右子树导致不平衡，应进行的旋转操作是？
- **难度**：medium
- **理由**：需要知道 AVL 树四种失衡类型（LL、RR、LR、RL）及对应的旋转方式。左孩子的右子树属于 LR 型，需先左旋再右旋。需理解原理后判断。
- **问题**：无

#### cs101_q25
- **题目摘要**：红黑树中，从任一节点到其所有后代叶节点的简单路径上黑色节点数相同，这一性质保证了最长路径不超过最短路径的多少倍？
- **难度**：medium
- **理由**：需要理解红黑树的性质并进行推理：最短路径全为黑节点，最长路径为黑红交替（红色节点的子节点必为黑），因此最长不超过最短的 2 倍。涉及 2-3 步逻辑链。
- **问题**：无

#### cs101_q39
- **题目摘要**：AVL 树中任意节点的平衡因子（左子树高度减右子树高度）的取值范围是？
- **难度**：easy
- **理由**：直接记忆性题目，AVL 树要求左右子树高度差的绝对值不超过 1，平衡因子取值为 {-1, 0, 1}。
- **问题**：无

#### cs101_q40
- **题目摘要**：在红黑树中插入新节点时，新节点的初始颜色通常设为？
- **难度**：medium
- **理由**：需要理解红黑树插入时设为红色的原因：红色节点不改变路径上黑色节点数，减少对红黑性质的破坏。需理解原理后判断。
- **问题**：无

#### cs101_q41
- **题目摘要**：在 AVL 树中插入一个节点导致失衡后，恢复平衡最多需要进行几次旋转？
- **难度**：medium
- **理由**：需要理解 AVL 树插入恢复平衡的旋转次数。LL 型和 RR 型需一次单旋，LR 型和 RL 型需双旋（两次旋转操作），但只需一次平衡调整即可恢复。
- **问题**：题目表述"最多需要进行几次旋转"与答案 A（1 次）存在歧义。详见问题汇总。

### Topic: 动态规划

#### cs101_q21
- **题目摘要**：在 0-1 背包问题中，状态 dp[i][j] 表示前 i 件物品在容量 j 下的最大价值。当 j >= w[i] 时状态转移方程为？
- **难度**：medium
- **理由**：需要理解 0-1 背包的状态转移：不选第 i 件则 dp[i-1][j]，选第 i 件则 dp[i-1][j-w[i]]+v[i]，取两者最大值。需理解 DP 原理后判断。
- **问题**：无

#### cs101_q26
- **题目摘要**：最长公共子序列（LCS）问题中，字符串 X 长度为 m、字符串 Y 长度为 n，使用动态规划求解的时间和空间复杂度分别为？
- **难度**：medium
- **理由**：需要理解 LCS 的 DP 解法：二维数组 m*n 个状态，每个状态转移 O(1)，因此时间和空间均为 O(m*n)。需理解算法后推断复杂度。
- **问题**：无

#### cs101_q47
- **题目摘要**：使用动态规划求解长度为 n 的数组的最长递增子序列（LIS），二维 DP 的时间复杂度为？
- **难度**：medium
- **理由**：需要理解 LIS 的 DP 解法：dp[i] 为以第 i 个元素结尾的 LIS 长度，每个状态遍历前面所有状态比较，共 n 个状态每个 O(n)，总计 O(n^2)。
- **问题**：题目表述"二维 DP"与解释不一致。详见问题汇总。

#### cs101_q48
- **题目摘要**：编辑距离（Levenshtein Distance）问题的动态规划解法中，dp[i][j] 表示什么？
- **难度**：medium
- **理由**：需要知道编辑距离 DP 的状态定义：dp[i][j] 表示将字符串 X 的前 i 个字符转换为 Y 的前 j 个字符所需的最少操作次数。需理解 DP 状态含义。
- **问题**：无

#### cs101_q49
- **题目摘要**：在 0-1 背包问题中，将二维 dp 数组优化为一维数组时，内层循环的遍历方向应为？
- **难度**：hard
- **理由**：需要深入理解一维优化的原理：逆序遍历保证 dp[j-w[i]] 引用的是上一轮的值，避免同一物品被重复使用。涉及对 DP 状态依赖关系的深入分析，容易与完全背包的正序遍历混淆，选项干扰性强。
- **问题**：无

## 三、发现的问题汇总

### 问题 1
- **题目 ID**：cs101_q41
- **问题类型**：表述/答案
- **问题描述**：题目问"在 AVL 树中插入一个节点导致失衡后，恢复平衡最多需要进行几次旋转？"，答案为 A（1 次）。但题目表述"几次旋转"按字面理解应为物理旋转操作次数。AVL 树中 LR 型和 RL 型失衡需要两次旋转（先左旋再右旋，或先右旋再左旋），因此"最多"应为 2 次旋转。解释中写道"LL 型和 RR 型失衡需一次单旋，LR 型和 RL 型失衡需一次双旋（两次旋转）"，其中"一次双旋（两次旋转）"的表述本身承认了双旋包含两次旋转操作，与答案"1 次"存在逻辑矛盾。此处将"一次双旋"作为"1 次平衡调整"来计数，但题目问的是"几次旋转"而非"几次平衡调整"，表述不够严谨。
- **建议**：将题目表述修改为"恢复平衡最多需要进行几次平衡调整（单旋或双旋均算一次）"，或直接将答案改为 B（2 次），使题目问"几次旋转"时答案与字面含义一致。

### 问题 2
- **题目 ID**：cs101_q47
- **问题类型**：表述
- **问题描述**：题目表述为"使用动态规划求解长度为 n 的数组的最长递增子序列（LIS），二维 DP 的时间复杂度为？"，但解释中描述的解法是"定义 dp[i] 为以第 i 个元素结尾的最长递增子序列长度"，这是一维 DP 而非二维 DP。标准 LIS 的 O(n^2) 解法使用一维数组 dp[i]，每个状态遍历前面所有状态比较。题目标注"二维 DP"不准确，与解释内容矛盾，容易误导学生认为 LIS 的标准 DP 解法使用二维数组。
- **建议**：将题目中的"二维 DP"修改为"动态规划"或"O(n^2) DP 解法"，使其与解释中描述的一维 dp[i] 解法一致。

## 四、审计总结

### 总体难度分布

cs101 题库 60 道选择题的难度分布为 easy 21 道（35.0%）、medium 35 道（58.3%）、hard 4 道（6.7%）。整体以 medium 为主，符合数据结构与算法课程的选择题难度预期。easy 和 medium 题目合计占 93.3%，能够覆盖大部分基础和中等难度知识点。hard 题目比例偏低（6.7%），对学有余力的学生挑战性不足。

### 各 Topic 难度梯度

大部分 Topic 的难度梯度较为合理（easy-medium 混合），但存在以下问题：
1. 链表 Topic 难度严重偏 easy（4 easy、0 medium），且从 easy 直接跳到 hard，缺少 medium 过渡。
2. 动态规划 Topic 完全缺少 easy 入门题（0 easy），对学生入门不够友好。
3. 8 个 Topic 没有 hard 题，部分 Topic（AVL 树与红黑树、排序算法、堆与优先队列）整体偏 medium，缺少拔高题。

### 发现的主要问题

本次审计共发现 7 个问题：
- 答案/表述问题 2 个：cs101_q41 的"几次旋转"表述与答案存在歧义；cs101_q47 的"二维 DP"表述与解释不一致。
- 难度分布问题 3 个：链表 Topic 偏 easy 且梯度断层；动态规划 Topic 缺 easy 入门题；整体 hard 题比例偏低。
- 知识点覆盖问题 1 个：并查集、Trie 树、最小生成树、拓扑排序、KMP 等重要知识点未考察。
- 选项设计问题 1 个：cs101_q03 的干扰项过于明显，区分度有限。

### 改进建议

1. 修正表述问题：优先修正 cs101_q41 和 cs101_q47 的表述与答案不一致问题。
2. 优化难度梯度：在链表 Topic 增加 medium 难度题目，在动态规划 Topic 增加 easy 概念题，在偏 medium 的 Topic 适当增加 hard 题。
3. 扩充知识点覆盖：在后续题库迭代中增加并查集、Trie 树、最小生成树、拓扑排序等重要知识点的题目。
4. 提升干扰项质量：对过于明显的干扰项（如 cs101_q03 选项 B）进行优化，增强区分度。
5. 核实题目数量：任务描述称 cs101 有 55 道题，但实际数据源有 60 道题，建议核实题库管理文档中的数量记录。
