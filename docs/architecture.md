# 技术架构

```

└────────────────────────┬────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────┐
│                 AI / Web 后端 (Next.js)               │
│                                                       │
│  ┌─────────────┐   ┌─────────────┐   ┌────────────┐ │
```

## 设计原则

1. **AI 能力服务端化**：复杂逻辑（多 Agent 编排、RAG、任务规划）放在后端，鸿蒙端只负责交互与系统体验。
2. **可解释性**：课程检索问答在主 Agent 实际返回 `citations` 时展示引用；Plan 等输出不保证引用。
3. **安全优先**：Safety Agent 对所有输出做内容安全审核与反幻觉检查。
4. **渐进式 RAG**：初期用本地 JSON/SQLite 简化向量检索，验证流程后再接正式向量库。
5. **静态资产与用户状态分离**：课程知识、预置题库和资源索引保持只读；计划、答题、画像、对话和上传内容写入本地 JSON 快照，服务重启后恢复。
5. **鸿蒙原生体验**：利用卡片、通知、元服务、跨设备能力打造系统级亮点。

## 多 Agent 编排流程

```
用户输入
   │
   ▼
┌──────────────┐
│ Orchestrator │ ── 意图识别 ── 决定调用哪些 Agent
└──────┬───────┘
       │
       ├──▶ Profile Agent   ── 加载用户画像（学段、薄弱点、偏好）
       ├──▶ Retrieval Agent ── RAG 检索相关课程资料
       │
       ▼ (按意图路由)
   ┌───────────────────────────────────┐
   │ Planner  │ Tutor │ Quiz │ Evaluator│
   └────────────────┬──────────────────┘
                   │
                   ▼
           ┌──────────────┐
           │ Safety Agent │ ── 审核 + 反幻觉
           └──────┬───────┘
                  │
                  ▼
            结构化输出 + 主 Agent 实际返回的引用（如有）
```

## 数据流

- **用户画像**：Profile Agent 维护，存储学习风格、薄弱知识点、历史表现。
- **知识库**：课程资料切片后存入本地索引，Retrieval Agent 按语义检索。
- **学习计划**：Planner Agent 生成，拆解为可执行任务项。
- **测验记录**：Quiz Agent 出题，Evaluator Agent 分析答题数据定位薄弱点。

## 鸿蒙端系统体验亮点

| 能力 | 用途 |
|------|------|
| 服务卡片 | 桌面展示今日学习计划与进度 |
| 通知 | 任务提醒、测验到期 |
| 元服务 | 免安装快速查词/问答 |
| 跨设备 | 手机端学习、平板端阅读、手表端提醒 |
| 分布式数据 | 学习进度多端同步 |

## 技术选型依据

| 选型 | 理由 |
|------|------|
| Next.js App Router | 前后端一体，API Routes 直接承载 Agent 逻辑，部署简单 |
| TypeScript | 类型安全，降低多人协作与迭代成本 |
| Tailwind + shadcn/ui | 快速构建一致 UI，适配演示 |
| Vercel AI SDK | 流式输出、工具调用原生支持 |
| OpenAI 兼容接口 | Agent 创新方向不限模型，可灵活切换国内/国际模型 |
| 本地 SQLite/JSON | 初期零依赖，快速验证流程 |
