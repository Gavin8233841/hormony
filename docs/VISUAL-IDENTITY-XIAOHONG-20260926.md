# 小鸿：鸿学伴角色与界面使用规范

更新时间：2026-09-26。服务当前复赛演示版；角色是学习陪伴者，不代替课程内容和操作反馈。

## 角色定型

名字“小鸿”。原型是原创纸羽小鹅：乳白圆润的身体、前乳白后灰绿的双层折页冠羽、石墨色眼睛、杏色短喙、灰绿翼尖与脚。纸页暗示“学习”，灰绿呼应应用色；造型不使用华为或其他产品的商标元素。表情以专注、鼓励、安心为主，不用夸张二次元服饰或人设台词。

## 页面规则

- **学伴页**：无会话时全身像与欢迎卡合为一个主视觉；有会话时只在页首和学伴署名放头像。正文、引用、行动卡不重复画小鸿。入口 Tab 用清晰单色系统符号，避免把小尺寸彩色角色塞入导航。
- **今日和课程**：课程视觉由学习阶梯与各科小图承担；小鸿不叠放在主卡或课程卡上。首页“问问学伴”用系统符号即可。
- **练习和结果**：正确、错误由文字与状态色先说明。未来庆祝姿态只在真正完成的结果页出现一次，不能把未提交的答题或手动勾选任务当作掌握证据。
- **动作**：学伴欢迎卡只在进入空态时淡入并上移 8vp；Tab 切换和主按钮轻微反馈保持当前原生 ArkUI 动画。动效不阻塞提问，不随每条流式内容反复播放。减少动态效果时应让信息本身仍完整可读。

## 排版与素材边界

一屏最多一个主视觉。主卡用深灰绿、奶油纸色内嵌操作区与小面积杏色暖调；课程用淡紫、灰绿区分，不让多种高饱和色同时争夺注意力。人物图像不得成为按钮唯一名称；交互保留文字、至少 48vp 主要触控区、真实可见的禁用和错误状态。
