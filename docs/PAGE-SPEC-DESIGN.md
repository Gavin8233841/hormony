## 设计令牌引用

所有页面规格中的颜色、圆角、字体、动画值均引用 `Constants.ets` 已定义的常量，不新增。

| 令牌 | 常量名 | 值 |
|------|--------|-----|
| 主文字 | `COLOR_TEXT_PRIMARY` | `#111827` |
| 次文字 | `COLOR_TEXT_SECONDARY` | `#6f7a8f` |
| 品牌蓝 | `COLOR_BRAND` | `#176bff` |
| 品牌浅底 | `COLOR_BRAND_LIGHT` | `#eaf2ff` |
| 成功 | `COLOR_SUCCESS` | `#2fb86b` |
| 警告 | `COLOR_WARNING` | `#f59e0b` |
| 错误 | `COLOR_ERROR` | `#e5484d` |
| 页面背景 | `COLOR_BG_PAGE` | `#f4f7fc` |
| 卡片背景 | `COLOR_BG_CARD` | `#ffffff` |
| 骨架屏 | `COLOR_BG_SKELETON` | `#e7edf6` |
| 边框 | `COLOR_BORDER` | `#e5ebf4` |
| 圆角小 | `RADIUS_SM` | 8 |
| 圆角中 | `RADIUS_MD` | 12 |
| 圆角大 | `RADIUS_LG` | 16 |
| 圆角特大 | `RADIUS_XL` | 20 |
| 动画快 | `ANIM_FAST` | 160 |
| 动画正常 | `ANIM_NORMAL` | 220 |

通用 Builder（已存在于 `Builders.ets`）：
- `TitleBar(title, subtitle, onBack)` — 统一标题栏带返回按钮
- `GradientHeader(title, subtitle, onBack)` — 渐变标题栏
- `EmptyState(message)` — 空状态占位
- `LoadingState()` — 加载状态占位

## 页面流程总览

```
课程 Tab
  └→ CourseDetail (课程详情：章节列表)
       └→ Lesson (知识点内容学习)
            ├→ Practice (精选练习)
            │    └→ QuizResult (测验结果)
            │         └→ Review (错题复习)
            └→ Resources (扩展资源)
                 └→ 外部链接（系统浏览器）

我的 Tab
  ├→ ActivityRecords (学习记录)
  ├→ MistakeBook (错题本)
  └→ Achievements (成就)
```

## 1. CourseDetail — 课程详情

### 导航
- **来源**：Course Tab 中点击课程卡片
- **返回**：`router.back()` 返回 Course Tab
- **传参**：`courseId`（string）、`courseTitle`（string）通过 `router.params` 传递

### 信息层级
1. **标题栏**：`GradientHeader`，title=课程名称，subtitle="共 N 个知识点"
2. **课程进度卡**：当前进度百分比 + 进度条 + 已学/总知识点数
   - 进度条使用 `COLOR_BG_PROGRESS_TRACK` 底色 + `COLOR_BRAND` 填充
   - 卡片圆角 `RADIUS_LG`，背景 `COLOR_BG_CARD`
3. **章节列表**：按 topic 分组的知识点条目
   - 每个 topic 分组标题：15fp 粗体 `COLOR_TEXT_PRIMARY`
   - 每个知识点条目：知识点名称（14fp）+ 掌握度标签（未学/学习中/已掌握）+ 右侧箭头 `sys.symbol.chevron_right`
   - 掌握度标签颜色：未学=`COLOR_TEXT_SECONDARY`、学习中=`COLOR_WARNING`、已掌握=`COLOR_SUCCESS`
4. **底部操作区**：两个并列按钮
   - "开始练习" — 主按钮，品牌蓝填充
   - "扩展资源" — 次按钮，品牌蓝描边

### 唯一主操作
- 点击知识点条目 → 进入 Lesson 页

### 状态
| 状态 | 展示 |
|------|------|
| loading | 3 个骨架屏卡片（`COLOR_BG_SKELETON`），保持稳定尺寸 |
| empty | `EmptyState("该课程还没有知识点内容")` |
| error | 错误文案 + "重试"按钮，`COLOR_ERROR` 文字 |
| offline | 从端侧 JSON 资产 `knowledge-chunks.json` 按 `courseId` 过滤加载，顶部提示"离线模式，显示本地课程内容" |
| complete | 正常展示章节列表，进度条反映已学知识点占比 |

### 设计令牌
- 卡片间距：22vp（首页区块间距规范）
- 内容水平边距：16vp
- 底部预留：88vp

## 2. Lesson — 知识点内容学习

### 导航
- **来源**：CourseDetail 点击知识点条目
- **返回**：`router.back()` 返回 CourseDetail
- **传参**：`courseId`、`topic`、`chunkId`（可选，定位到具体切片）

### 信息层级
1. **标题栏**：`GradientHeader`，title=知识点名称，subtitle=课程名称
2. **学习目标卡**（如有）：目标文本，14fp，`COLOR_BRAND_LIGHT` 背景
3. **知识内容区**：可滚动正文区域
   - 正文：15fp `COLOR_TEXT_PRIMARY`，行高 1.6
   - 来源标签：12fp `COLOR_TEXT_SECONDARY`，`sys.symbol.book` 图标
   - 复核状态标签：12fp，已复核=`COLOR_SUCCESS`，未复核=`COLOR_WARNING`
4. **上下篇导航**：底部固定区域
   - "上一篇" / "下一篇" 按钮，`sys.symbol.chevron_left` / `sys.symbol.chevron_right`
   - 当前位置指示器："3 / 52"

### 唯一主操作
- "学完了，去练习" — 底部品牌蓝主按钮，跳转 Practice 页

### 状态
| 状态 | 展示 |
|------|------|
| loading | 骨架屏正文块（3 行灰色条，保持稳定高度） |
| empty | `EmptyState("该知识点暂无内容")` |
| error | 错误文案 + "重试"按钮 |
| offline | 从端侧 JSON 资产 `knowledge-chunks.json` 读取，顶部提示"离线模式" |
| complete | 正文展示完毕，"学完了，去练习"按钮启用 |

### 设计令牌
- 正文卡片：`COLOR_BG_CARD`，`RADIUS_LG`，padding 20vp
- 来源标签底色：`COLOR_BG_TAG`
- 底部按钮区：padding-bottom 88vp

## 3. Practice — 精选练习

### 导航
- **来源**：Lesson 页"学完了，去练习"按钮 / CourseDetail "开始练习"按钮
- **返回**：`router.back()` 返回来源页
- **传参**：`courseId`、`topic`（可选，限定练习范围）

### 信息层级
1. **标题栏**：`GradientHeader`，title="精选练习"，subtitle=课程名称 · 知识点
2. **题目来源标识**：固定标签"离线精选题库"，`COLOR_SUCCESS_LIGHT` 背景，与 AI 出题明确区分
3. **题号与进度**：当前题号 / 总题数 + 进度条
4. **题干区**：题目文本，16fp `COLOR_TEXT_PRIMARY`
5. **选项区**：4 个选项卡片
   - 未选：`COLOR_BG_CARD` + `COLOR_BORDER` 描边
   - 已选：`COLOR_BRAND_LIGHT` + `COLOR_BRAND` 描边
   - 正确（提交后）：`COLOR_SUCCESS_LIGHT` + `COLOR_SUCCESS` 描边
   - 错误（提交后）：`COLOR_ERROR_LIGHT` + `COLOR_ERROR` 描边
   - 每个选项卡片左侧：A/B/C/D 圆形标识
6. **操作区**：上一题 / 下一题 / 提交评分

### 唯一主操作
- "提交评分" — 完成全部题目后启用的主按钮

### 状态
| 状态 | 展示 |
|------|------|
| loading | 骨架屏题干 + 4 个选项骨架 |
| empty | `EmptyState("该知识点暂无精选练习题")` |
| error | 错误文案 + "重试"按钮（端侧资产读取失败时） |
| offline | 从端侧 JSON 资产 `quizzes.json` 按 `courseId`/`topic` 过滤，完全离线可用，顶部标签"离线精选题库" |
| complete | 提交后跳转 QuizResult 页 |

### 设计令牌
- 选项卡片：`RADIUS_MD`，padding 16vp，间距 12vp
- 选项圆形标识：28x28vp，`RADIUS_SM`
- 按钮高度：44vp
- 底部预留：88vp

## 4. QuizResult — 测验结果

### 导航
- **来源**：Practice 页提交评分后跳转
- **返回**：`router.back()` 返回 CourseDetail（不返回 Practice，避免重复答题）
- **传参**：`QuizResult` 对象通过 `router.params` 或 AppStorage 传递

### 信息层级
1. **标题栏**：`GradientHeader`，title="练习结果"，subtitle=课程 · 知识点
2. **成绩概览卡**：大数字正确率 + 正确/总数 + 用时
   - 正确率≥80%：`COLOR_SUCCESS`
   - 正确率 60-79%：`COLOR_WARNING`
   - 正确率<60%：`COLOR_ERROR`
   - 卡片背景 `COLOR_BG_CARD`，圆角 `RADIUS_LG`
3. **逐题解析列表**：可展开/收起
   - 每题：题号 + 正确/错误图标 + 题干摘要
   - 展开后：你的答案（红）、正确答案（绿）、解析文本
   - 正确图标：`sys.symbol.checkmark_circle_fill`，`COLOR_SUCCESS`
   - 错误图标：`sys.symbol.xmark_circle_fill`，`COLOR_ERROR`
4. **薄弱知识点提示**（如有）：标签形式展示
5. **底部操作区**：三个按钮
   - "错题重做" — 主按钮（仅在有错题时启用）
   - "问学伴讲解" — 次按钮，跳转 Chat Tab 并携带错题上下文
   - "返回课程" — 文字按钮

### 唯一主操作
- "错题重做" — 跳转 Review 页（仅错题），无错题时灰显

### 状态
| 状态 | 展示 |
|------|------|
| loading | 骨架屏成绩卡 + 3 个题目骨架 |
| empty | 不适用（QuizResult 必有数据） |
| error | 不适用（结果在本地计算） |
| offline | 完全离线可用，结果数据来自本地评分 |
| complete | 全部展示完毕，底部按钮可用 |

### 设计令牌
- 成绩大数字：48fp 粗体
- 逐题项卡片：`RADIUS_MD`，padding 16vp
- 解析文本：14fp `COLOR_TEXT_SECONDARY`
- 底部预留：88vp

## 5. Review — 错题复习

### 导航
- **来源**：QuizResult "错题重做"按钮 / MistakeBook 点击错题条目
- **返回**：`router.back()` 返回来源页
- **传参**：`courseId`、`topic`（可选）、`mistakeIds`（可选，指定复习的错题 ID 列表）

### 信息层级
1. **标题栏**：`GradientHeader`，title="错题复习"，subtitle=错题数量
2. **来源标识**："离线精选题库 · 错题重做"标签
3. **题号与进度**：当前题号 / 总题数 + 进度条
4. **题干区**：题目文本，16fp
5. **选项区**：4 个选项（同 Practice 页样式）
6. **上次答题记录**（如有）：灰色小字"上次你选择了 B，答案错误"
7. **操作区**：上一题 / 下一题 / 完成复习

### 唯一主操作
- "完成复习" — 全部答完后启用，提交后更新错题状态

### 状态
| 状态 | 展示 |
|------|------|
| loading | 骨架屏题干 + 选项骨架 |
| empty | `EmptyState("没有待复习的错题")` |
| error | 错误文案 + "重试"按钮 |
| offline | 从端侧 JSON 资产 + ArkData 错题记录加载，完全离线可用 |
| complete | 展示复习结果摘要（本次答对/总数），"返回"按钮 |

### 设计令牌
- 与 Practice 页保持一致的选项卡片样式

## 6. Resources — 扩展资源

### 导航
- **来源**：CourseDetail "扩展资源"按钮
- **返回**：`router.back()` 返回 CourseDetail
- **传参**：`courseId`、`courseTitle`

### 信息层级
1. **标题栏**：`GradientHeader`，title="扩展资源"，subtitle=课程名称
2. **资源类型筛选**（可选）：全部 / 教材 / 课程 / 工具 / 文档
   - 筛选按钮组，选中态品牌蓝填充
3. **资源列表**：卡片形式
   - 每张卡片：资源标题（16fp 粗体）+ 类型标签 + 描述摘要（14fp `COLOR_TEXT_SECONDARY`）+ 来源域名
   - 类型标签颜色：教材=`COLOR_BRAND_LIGHT`、课程=`COLOR_SUCCESS_LIGHT`、工具=`COLOR_WARNING`浅底、文档=中性
   - 右侧：`sys.symbol.arrow_up_right_square` 外链图标
4. **离开提示**：点击资源时弹出确认对话框"即将离开鸿学伴，前往外部网站"

### 唯一主操作
- 点击资源卡片 → 确认后打开系统浏览器

### 状态
| 状态 | 展示 |
|------|------|
| loading | 3 个骨架屏资源卡片 |
| empty | `EmptyState("该课程暂无扩展资源")` |
| error | 错误文案 + "重试"按钮 |
| offline | 从端侧 JSON 资产 `external-resources.json` 按 `courseId` 过滤加载，完全离线可用 |
| complete | 正常展示资源列表 |

### 设计令牌
- 资源卡片：`COLOR_BG_CARD`，`RADIUS_LG`，padding 16vp，间距 12vp
- 类型标签：`RADIUS_SM`，padding 4x8vp
- 底部预留：88vp

### 静态预览建议

## 设计约束总结

1. **不新增路由入口**：所有新页面通过 `router.pushUrl` 从已有页面进入，不修改 Index Tab 结构
2. **不修改仓库 schema**：页面规格仅引用 `DataModels.ets` 已有接口，不新增数据模型
3. **复用设计令牌**：所有颜色、圆角、字体大小引用 `Constants.ets`，不硬编码新值
4. **复用鸿蒙系统 Symbol**：仅使用 `sys.symbol.*` 资源，不引入第三方图标库
5. **状态完整**：每个页面必须实现 loading/empty/error/offline 五态
6. **离线优先**：端侧 JSON 资产为离线数据源，API 为在线增强
7. **来源区分**：精选题库明确标注"离线精选题库"，与 AI 出题严格区分
8. **单一入口**：同一功能在顶层只出现一个入口，不在多处重复
9. **不设计算法**：进度计算、掌握度、间隔复习、成就规则等算法由 Codex 定义领域接口后实现
