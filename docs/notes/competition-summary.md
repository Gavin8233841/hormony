# 竞赛规则摘要

> 来源：C4-AI 官方页面与 FAQ。**最终以登录茶思屋后下载的官方附件为准。**

## 赛事概况

- **全称**：2026 中国高校计算机大赛-人工智能创意赛（C4-AI）
- **总入口**：https://developer.huaweicloud.com/c4ai.html
- **双赛道**：鸿蒙高校创新赛 / 昇腾 AI 创新大赛
- **主办**：全国高等学校计算机教育研究会
- **承办**：华为公司与浙江大学联合承办
- **面向**：中国内地及港澳台地区高校在校生

## 鸿蒙高校创新赛

- 官方页面：https://developer.huawei.com/consumer/cn/activity/incentive/C4
- 开放式命题
- 鼓励基于 HarmonyOS 技术进行创新开发

## 参赛对象与组队

- 中国内地及港澳台地区高等学校在册在校学生（专科/本科/硕士/博士）
- 不限专业
- 可单人或组队，每队不超过 3 人
- 可跨学校、跨专业组队
- 同一队员只能报名一个队伍
- 每队须有一名指导老师，须为队长所属高校正式教师

## 作品方向

1. 应用创新
2. **Agent 创新**（本项目选择）
3. 用户体验创新
4. 操作系统智能创新

### Agent 创新方向关键规则

- **FAQ 第 13 条：不限制模型 API 的使用**
- 参赛队伍可自由选择市场上可用的 AI 工具及模型 API

## 测试设备

- 大赛不提供硬件设备
- 可使用自有设备、官方开发工具自带模拟器、云测试/云调试

## 作品提交

- 截止前可多次更新作品（FAQ 写至多 10 次）
- 晋级后只能基于初赛原作品迭代优化，不得换新作品
- 提交入口：官方页面"提交作品" → 华为 OAuth → 黄大年茶思屋平台
